# Smart Factory Decision Support Assistant

## Project Overview

Smart Factory Decision Support Assistant is an AI-based smart manufacturing system that helps factory managers, engineers and supervisors analyze production, machines, inventory and quality data.

## Main Features

- Production Analysis
- Production Forecasting
- Machine Status Monitoring
- Inventory Analysis
- Quality Analysis
- AI Recommendations
- Alerts
- What-if Analysis
- AI Assistant
- Computer Vision based Defect Detection

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Plotly
- OpenCV
- YOLO / Ultralytics
- Pillow
